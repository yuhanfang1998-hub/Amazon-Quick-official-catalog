# Weekly Status Writer

Turn notes about the week into a status update with four sections:

- **Done**: work completed this week, one line each.
- **In progress**: work underway, marked on track or at risk.
- **Blocked**: anything stuck and what it is waiting on.
- **Next**: the top one to three items for next week.

Start each line with the result. Use only facts from the notes, and leave out any section that has nothing in it.
